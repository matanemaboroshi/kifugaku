プライバシーポリシー

制定日：2026年10月26日

ふるログ（以下「当サイト」）と、当サイトの運営者が運営する YouTube チャンネル「返礼品ランキングちゃんねる」（以下「当チャンネル」）における、情報の取り扱いについて定めます。

当サイトが集める情報

当サイトは、お名前・メールアドレスなどの個人情報の入力を求めません。アクセス解析ツール（Google アナリティクスなど）や、当サイト独自の Cookie は使っていません。「残り枠から探す」に入力した金額は、お使いの端末の中だけで計算に使い、どこにも送信・保存しません。

外部のサービスに送られる情報

  • 楽天市場の商品画像：楽天の画像サーバーから読み込むため、お使いの端末の IP アドレスなどが楽天グループ株式会社に送られます。
  • 文字の表示（動画で紹介した返礼品のページ）：Google Fonts を使うため、IP アドレスなどが Google LLC に送られます。
  • ページの配信：当サイトは GitHub Pages（GitHub, Inc.）で配信しています。
  • 楽天アフィリエイト：返礼品のリンクを押すと楽天のサイトに移動し、楽天が Cookie などで紹介元を記録します。取り扱いは楽天グループのプライバシーポリシーをご覧ください。

YouTube API サービスの利用

当チャンネルは、動画の投稿と再生数などの集計のために YouTube API サービスを使っています。使うのは運営者自身のチャンネルの情報だけで、視聴者の方の情報を取得・保存することはありません。YouTube の利用にはYouTube 利用規約が適用され、Google による情報の取り扱いはGoogle プライバシーポリシーに従います。運営者のチャンネルへのアクセスは、Google アカウントの設定画面からいつでも取り消せます。

広告について

当サイトと当チャンネルは楽天アフィリエイトに参加しています。リンク先で寄付が行われた場合、運営者が紹介料を受け取ることがあります。
