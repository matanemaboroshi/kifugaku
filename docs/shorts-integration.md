# ショート動画との連携仕様

このサイトは、ショート動画の自動作成で使う「データ」と「動画ごとのリンク集ページ」を提供する。ショート動画側はこの仕様だけを見れば連携できる。

## 1. データ：`api/feed.json`

公開URL：`https://matanemaboroshi.github.io/kifugaku/api/feed.json`（毎朝6時ごろ更新）

| キー | 中身 |
|---|---|
| `generated` | 記録日（`YYYY-MM-DD`） |
| `site` | サイトのURL |
| `days_recorded` | 記録した日数 |
| `categories` | カテゴリのスラッグと表示名の対応（例：`"meat": "肉"`） |
| `price_down_7d` | 直近7日に値下げされた返礼品（新しい順、最大50件） |
| `kg_per_10k` | カテゴリごとの「1万円でもらえる量」上位10件（肉・魚介・米・果物・野菜） |
| `momentum` | 直近のレビュー増加数が多い返礼品 上位20件（`review_growth` つき） |
| `teiban` | 定番（直近30日の80%以上で人気上位）上位20件。記録14日目以降に入る |
| `by_category` | カテゴリごとのレビュー数上位10件（麺類・ご当地グルメ・伝統工芸品・アイデア雑貨・家電・旅行体験を含む全カテゴリ） |

### 返礼品の項目

| キー | 中身 |
|---|---|
| `code` | 楽天の商品コード（`ショップコード:商品ID`）。動画ページの指定にも使う |
| `name` | 返礼品名（先頭の「【ふるさと納税】」は除いてある） |
| `shop` | 自治体名 |
| `category` | カテゴリのスラッグ |
| `price` | 寄付額（円） |
| `reviews` / `review_avg` | レビュー件数 / 平均評価 |
| `kg` / `kg_per_10k` | 返礼品名から読み取った重さ / 1万円あたりの量（読み取れないときは `null`） |
| `page` | このサイトの返礼品ページ（寄付額の推移つき） |
| `url` | 楽天のアフィリエイトリンク |
| `image` | 商品画像のURL（楽天の画像。動画に使うかどうかは権利を確認してから決める） |

値下げの項目には、さらに `date`（記録日）、`before` / `after`（寄付額）、`diff`（差額）、`pct`（変化率%）が入る。

### 使うときの注意
- 数字はすべて「当サイトの記録時点」のもの。動画では「〇月〇日時点」と日付を必ず添える。
- 「最安」「No.1」などの言葉は使わない。使えるのは「当サイトの記録で〇月〇日に〇円値下げ」のように、記録に基づく言い方だけ。
- `kg_per_10k` は返礼品名から自動で読み取った目安。動画でも「目安」と書く。

## 2. 動画ごとのリンク集ページ：`data/videos/<id>.json`

動画を予約投稿したら、ショート動画側（`matanemaboroshi/shorts` の publish-video）が、このリポジトリの `data/videos/` に1本につき1ファイル置く。push されるとサイトが作り直され（楽天からの取得はしない）、`v/<id>.html` ができる（検索エンジンには載せない設定）。

```json
{
  "id": "2026-11-01-meat",
  "title": "1kgあたりで比べた肉の返礼品 5選",
  "published": "2026-11-01",
  "youtube_id": "xxxxxxxxxxx",
  "ranking": "順位の付け方：1kgあたりの寄付額が少ない順（10月30日時点）",
  "note": "動画の寄付額は10月30日時点の記録です。",
  "items": [
    {"code": "f402052-iizuka:10000315", "label": "第1位", "name": "鉄板焼ハンバーグ", "video_price": 14000, "video_price_date": "2026-10-30"},
    {"code": "f000000-xxxx:12345", "label": "第2位"}
  ]
}
```

| キー | 必須 | 中身 |
|---|---|---|
| `id` | ○ | 英数字とハイフンだけ。ページのURLになる（`<サイトのURL>/v/<id>.html`）。ほかの文字が入ったファイルは読み飛ばす |
| `title` | ○ | 動画のタイトル |
| `published` | ○ | 公開日（`YYYY-MM-DD`、日本時間）。**この日になるまで一覧ページに出さない**（予約投稿のため）。ページ自体は先に作られる |
| `items[].code` | ○ | `feed.json` の `code` と同じ（`ショップコード:商品ID`） |
| `items[].label` | | 動画内での呼び方（「第1位」など）。省略すると番号になる |
| `items[].name` | | 動画の画面に出した短い名前。返礼品名の上に太字で出す |
| `items[].video_price` / `video_price_date` | | 動画で使った寄付額とその日付（記録用。ページには最新の記録を出す） |
| `ranking` / `note` | | 順位の付け方、動画のデータの日付。タイトルの下に出す |
| `youtube_id` | | 公開日になったら「動画を見る（YouTube）」のリンクを出す |

- ページの先頭には、全ページ共通の PR 表示（「本ページはプロモーション（楽天アフィリエイト）を含みます。」）が出る。
- 寄付額とリンクはビルドのたびに最新の記録から入れ直し、「寄付額の推移を見る」で返礼品ページ（推移のグラフつき）につなぐ。記録対象から外れた返礼品は、リンクだけ残して「記録対象外」と表示する。
- アフィリエイトのリンクはこのサイトが作る。ショート動画側はアフィリエイト ID を持たない。

一覧ページ：`<サイトのURL>/v/index.html`
チャンネルのプロフィールのリンクには、この一覧ページを設定する。

## 3. 商品データの取り込み

`data/catalog.json` の各返礼品には、`image`（1枚目の画像）のほかに `images`（楽天の商品検索 API が返す画像すべて、最大3枚）が入る。ショート動画側はこの中から、人物・文字・デザインの入っていない1枚を選んで使う。


ショート動画側は、このリポジトリの `config.json`・`data/catalog.json`・`data/daily/` を直接読み、動画用の商品データを作る（shorts の `pipeline/video/moremoney.py`）。項目名や形を変えるときは、shorts 側も合わせて直す。重さの読み取り（`parse_kg`）は両方で同じ規則にしてある。
