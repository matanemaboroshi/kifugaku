# デザインのルール（ふるログ）

サイトの見た目を変えるときは、このページと `.claude/skills/frontend-design/SKILL.md`（Anthropic 公式のスキル、Apache 2.0）に従います。変えたら、スマホ幅（390px）とパソコン幅（1280px）の画面写真で確かめます。

## 題材・読者・目的
- 題材：楽天ふるさと納税の返礼品の寄付額を毎日記録したデータ
- 読者：YouTube ショート「返礼品ランキングちゃんねる」から来た、スマホの人
- 目的：動画の返礼品と寄付額をすぐ確かめて、楽天の返礼品ページへ進んでもらう

## 方向性：動画とおそろい（2026-10-27 オーナー決定）
ショート動画と同じ紺・赤・金を使い、動画から来た人に同じ運営だと一目で分かるようにする。目立たせるのはトップの赤い放射線の帯の1か所だけで、ほかは白い面と罫線で静かにまとめる。

| 名前 | 値 | 使う場所 |
|---|---|---|
| navy | `#14213D` | ヘッダー・フッター・見出しの文字 |
| red | `#E0262B` | トップの帯、ボタン、見出しの左の線 |
| sale | `#D6001C` | 寄付額の数字、「▼ ○円下がった」 |
| gold | `#F2C14E` | 選択中のタブ、1つ目の枠、フォーカス |
| bg | `#F1F3F7` | ページの地 |

- 書体：見出しは Noto Serif JP 900（動画の字幕と同じ。Google Fonts、OFL）。本文は端末のゴシック。商品名は長いので、見出しでもゴシックの太字にする。
- 数字は `font-variant-numeric: tabular-nums`。寄付額は右揃え。
- ロゴ：`brand/logo.svg`（白地用）・`brand/logo-dark.svg`（紺地用、ヘッダーの `assets/logo.svg` と同じ）・`assets/mark.svg`（ファビコン）。キャッチコピーは付けない。文字は Zen Maru Gothic（OFL）をアウトライン化したもの。

## 画面の構成（2026-10-27 オーナーの指摘を反映）
- タブは「トップ・人気急上昇・値下げ・予算で探す」の4つを中央にそろえる。「1万円あたりの量」はカテゴリページとフッターから。
- トップは人気急上昇ランキング（直近のレビューの増え方の順）の1〜3位を赤い帯に、4〜10位をその下に置く。
- 一覧の商品名は、出品者の宣伝文句（「累計○箱突破」「総合1位」「送料無料」など）を外した短い名前にする。元の商品名は商品ページの「楽天での商品名」に出す。
- 一覧は件数を出し、途中で切るときは「もっと見る（残り○件）」や「○位まで見る」で続きがあることを示す。

## しないこと
- 運営側の事情（「毎日記録」「記録○日目」「○品を記録中」など）や、見出しの下の補足文（サブタイトル）を画面に出さない。説明が要るものは「このサイトについて」にまとめる（2026-10-27 オーナーの指摘）。
- 王冠・根拠のない「No.1」「最安」などの飾りや言葉、架空の利用者の声（景品表示法・ステマ規制）。順位は数字で示す。
- 全セクションのフェードイン、すべてのカードのホバー演出。
- 見出しの一部の語だけ色を変える、英字の全大文字ラベル。
- 他社サイトの文言・画像・ロゴの流用。
